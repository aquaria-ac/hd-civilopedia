# 和而不同 · 文明百科

《文明 VI》和而不同模组的简体中文网页百科，当前内容为 V43。

- 3393 个详情页面，3116 个列表条目。
- 包含分类、标题优先搜索、游戏图标、条目关联与悬浮详情。
- 机制分类包含战斗、经济、行动与探索、宗教、AI、文化、外交等条目。
- 纯静态网页，所有运行资源随仓库提供。

## 访问

https://aquaria-ac.github.io/hd-civilopedia/

GitHub Pages 使用 `main` 分支根目录；`.nojekyll` 保留静态文件原样发布。

## 本地使用

下载仓库后打开 `index.html`，或使用任意静态文件服务器。
