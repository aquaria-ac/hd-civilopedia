# 和而不同 · 文明百科

《文明 VI》和而不同模组的简体中文网页百科，当前内容为 V51。

- 3394 个详情页面，3117 个列表条目。
- 包含分类、中文/全拼/拼音首字母搜索，名称开头匹配优先；支持游戏图标、条目关联与悬浮详情。
- 机制分类包含战斗、经济、行动与探索、宗教、AI、文化、外交、伟人等条目。
- 伟人与伟人点条目包含10组、228项加成来源，采用游戏内正式描述，支持来源与前提跳转。
- 住房条目包含住房计算、水源与区域规则、人口增长限制及7组81项正式描述的加成来源。
- 旅游业绩与游客条目包含10组184项来源，覆盖主题化、转换、倍率及一次性业绩；排除只增加固定旅游数值的来源。
- 市立公园、公司等32个改良的详情与悬浮说明包含产出转旅游业绩的比例和解锁前提。
- 商路收益条目新增劫掠商路小节，包含产出折算、速度系数、50金币保底和加成算例。
- 纯静态网页，所有运行资源随仓库提供。
